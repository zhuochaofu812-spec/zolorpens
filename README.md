# Zolor Pens

一个使用 Next.js + Tailwind CSS 构建的高端黑金金属笔官网首页原型，视觉参考 Apple 的克制科技感与 Montblanc 的奢侈书写仪式感。

## 功能亮点

- 全屏首屏宣传视频层，包含黑金动态光效与视频 poster 回退。
- 高级动画：金属流光文字、入场渐显、悬浮钢笔、光晕视差与产品卡片 3D hover。
- 产品展示区：三款高端金属笔卡片，包含价格、材质描述与玻璃拟态信息层。
- 工艺与礼赠转化模块，适合继续扩展品牌故事、规格详情和预约咨询。

## 开发命令

```bash
npm install
npm run dev
npm run build
```
